02 // quién_soy

Quién soy

Mi nombre es Delwins Rivas y soy un desarrollador web (frontend) y de software con base en Caracas, Venezuela. Combino código con criterio de diseño y visión de marketing para construir productos digitales que no solo funcionan, sino que comunican.

Trabajo con HTML, CSS, JavaScript y XML, y actualmente estoy profundizando en Python. Uso Git para mantener todo versionado y ordenado. Me muevo con comodidad entre lo técnico y lo creativo: del wireframe al deploy, del concepto de marca a la landing que convierte.
